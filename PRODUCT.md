# Product

## Register

product

## Users

TakkieAI is for people who write throughout the workday and want to dictate naturally without leaving the app they are using. They may be in email, chat, documents, project tools, or code editors and need a fast, dependable push-to-talk workflow that works across Windows and macOS.

## Product Purpose

TakkieAI turns speech into polished text at the current cursor and captures Windows meetings using the user's own Gemini API key. Notetaker records microphone and system audio, keeps recoverable local files, and produces searchable transcripts, summaries and action items. Google Calendar supplies upcoming meetings; a local MCP server exposes only explicitly shared notes.

## Brand Personality

Calm, capable, and human. The interface should feel quietly responsive and trustworthy, with small moments of Google-inspired color and motion reserved for recording, processing, and success feedback.

## Anti-references

For the Windows redesign, Fahim's September 2026 screenshots establish the Wispr Flow-like layout: a warm white sidebar, inset white workspace, grouped settings and a tiny black recording capsule. Keep TakkieAI's name, show real local information, and omit subscriptions and team administration. Avoid decorative gradients, invented usage statistics and controls that imply unsupported integrations.

## Design Principles

- Stay in the user's flow: the desktop UI should disappear behind the task.
- Record first, recover always: every failure path must preserve the user's words.
- Make system state obvious: listening, locked, processing, inserted, offline, and error states must never be ambiguous.
- Earn trust through local control: keys, history, dictionary, and retention remain understandable and user-controlled.
- Prefer familiar platform behavior: use standard Windows affordances and keyboard behavior wherever possible.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the app surfaces. Support keyboard-only operation, visible focus, high-contrast Windows themes, screen-reader names, reduced motion, color-independent states, scalable text, and clear alternatives when global shortcuts or automatic insertion are unavailable.
