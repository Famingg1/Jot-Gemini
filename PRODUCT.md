# Product

## Register

product

## Users

Jot is for people who write throughout the workday and want to dictate naturally without leaving the app they are using. They may be in email, chat, documents, project tools, or code editors and need a fast, dependable push-to-talk workflow that works across Windows and macOS.

## Product Purpose

Jot turns speech into polished text at the current cursor using the user's own Gemini API key. Success means recording begins immediately, self-corrections and formatting are handled well, text lands in the intended app, and no spoken work is lost when the network or insertion path fails.

## Brand Personality

Calm, capable, and human. The interface should feel quietly responsive and trustworthy, with small moments of Google-inspired color and motion reserved for recording, processing, and success feedback.

## Anti-references

Avoid a chat application, a transcription dashboard that must stay open, decorative AI gradients, dense enterprise settings, and unfamiliar custom controls. Do not imitate Wispr Flow's branding or proprietary visuals; match the speed and workflow quality with Jot's own identity.

## Design Principles

- Stay in the user's flow: the desktop UI should disappear behind the task.
- Record first, recover always: every failure path must preserve the user's words.
- Make system state obvious: listening, locked, processing, inserted, offline, and error states must never be ambiguous.
- Earn trust through local control: keys, history, dictionary, and retention remain understandable and user-controlled.
- Prefer familiar platform behavior: use standard Windows affordances and keyboard behavior wherever possible.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the app surfaces. Support keyboard-only operation, visible focus, high-contrast Windows themes, screen-reader names, reduced motion, color-independent states, scalable text, and clear alternatives when global shortcuts or automatic insertion are unavailable.
